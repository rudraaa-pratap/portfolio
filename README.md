## ⚙️ Run Locally

Clone the project

```bash
git clone https://github.com/rudraaa-pratap/portfolio.git
```

Go to the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
