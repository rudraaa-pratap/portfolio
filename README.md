## About

Welcome to my personal portfolio! This space is designed to give you a quick glimpse into my work, the technologies I use, and the projects I've built. It's built from the ground up using **React.js** and **Vite**, focusing on clean code, solid performance, and a modern aesthetic.

---

## Tech Stack

This project was built using the following modern web technologies:

- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Language:** JavaScript (ES6+)
- **Styling:** HTML5 & Vanilla CSS (with modern CSS variables and flexbox/grid)
- **Deployment:** Vercel

## Quick Start (Run Locally)

Want to explore the code or run it on your own machine? Follow these simple steps:

### 1. Clone the repository
```bash
git clone https://github.com/rudraaa-pratap/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

Your app will be available at `http://localhost:5173`.
